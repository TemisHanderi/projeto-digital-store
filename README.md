# 🛍️ Digital Store 

## Sobre o projeto
A Digital Store é uma loja virtual desenvolvida com foco em oferecer uma experiência moderna, intuitiva e eficiente para os usuários. O projeto conta com uma homepage atrativa, uma página de listagem de produtos organizada e uma área dedicada à visualização detalhada de cada item, permitindo que o cliente explore informações de forma clara e objetiva.
